          How do I get the comments?
          
    
            
  1. On a computer, open the post on instagram.com and keep scrolling the comments until the last one is showing. Instagram loads them in batches.
    2. 
            
  2. Select from the first comment to the last, copy, and paste here. Usernames, likes, times and Reply links are sorted out for you.
    3. 
            
  3. For a post with hundreds of comments, a comment export tool is quicker. Drop its CSV or JSON file onto the box.
    4. 
            
  4. You can also type one comment per line with the username first, or paste a plain list of usernames.
